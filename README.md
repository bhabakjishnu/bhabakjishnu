## <a id="about"></a>About

I am a software developer and Computer Science student focused on building robust, performant, and accessible software. My work bridges modern web standards with pragmatic backend engineering—delivering clean user experiences powered by reliable server architecture.

### Engineering Philosophy
- **Web Standards First**: Leveraging native HTML5, modern CSS3, and modern ECMAScript to construct lightweight, zero-bloat user interfaces before reaching for heavy abstractions.
- **Systematic Design**: Designing with centralized design tokens, fluid typography scales, and modular component structures that scale cleanly.
- **Server Security & Reliability**: Building modular backend services in Python (Flask) with strict separation of concerns and server-side credential isolation.

## <a id="selected-projects"></a>Selected Projects

A curated selection of verified open-source projects and live deployments demonstrating architectural precision, web standards, and full-stack capabilities.

### Featured Deployments

#### 1. [Weather Intelligence Dashboard](https://github.com/bhabakjishnu/Weather-App)
> Full-stack weather analytics application featuring server-side credential isolation and real-time atmospheric metrics.

- **Architecture**: Decoupled Python Flask backend serving a lightweight, vanilla JavaScript and CSS frontend interface.
- **Key Technical Highlights**:
  - Secure proxy architecture shielding third-party weather API credentials server-side.
  - Live query resolution for global locations with atmospheric calculations (temperature, perceived humidity, wind velocity).
  - Responsive, modern dashboard UI engineered without external CSS frameworks.
- **Stack**: `Python` • `Flask` • `JavaScript (ES6+)` • `Modern CSS3` • `REST API`
- **Links**: [Repository](https://github.com/bhabakjishnu/Weather-App) &bull; [Live Demo](https://weather-app-phi-snowy-94.vercel.app/)

#### 2. [Nexora Studio — Agency Landing Platform](https://github.com/bhabakjishnu/Agency-Landing-Page)
> High-performance digital agency landing page demonstrating zero-dependency frontend engineering.

- **Architecture**: Strictly semantic HTML5 and modern CSS3—zero JavaScript runtime overhead and zero CSS preprocessors.
- **Key Technical Highlights**:
  - Centralized design token system (`:root` CSS variables) managing color palettes, shadows, and spacing scales.
  - Responsive multi-column layout utilizing CSS Grid and Flexbox with mobile-first media queries.
  - Interactive glassmorphism cards and smooth elevation transitions.
- **Stack**: `Semantic HTML5` • `Modern CSS3` • `Responsive Design`
- **Links**: [Repository](https://github.com/bhabakjishnu/Agency-Landing-Page) &bull; [Live Demo](https://bhabakjishnu.github.io/Agency-Landing-Page/)

#### 3. [SaaS Pricing & Feature Matrix](https://github.com/bhabakjishnu/SaaS-Pricing-Feature-Matrix)
> Accessible, responsive multi-tier SaaS subscription comparison matrix built for enterprise web standards.

- **Architecture**: Clean tabular and CSS Grid matrix balancing deep data density with mobile readability.
- **Key Technical Highlights**:
  - Fully accessible table structure with screen-reader friendly headers and keyboard navigation.
  - Tiered feature comparison system with visual hierarchy for highlighted/recommended plans.
  - Zero runtime dependencies for instant load performance.
- **Stack**: `HTML5` • `CSS Grid` • `Design Tokens` • `Accessibility (a11y)`
- **Links**: [Repository](https://github.com/bhabakjishnu/SaaS-Pricing-Feature-Matrix) &bull; [Live Demo](https://bhabakjishnu.github.io/SaaS-Pricing-Feature-Matrix/)

#### 4. [Animated UI Theme Pack](https://github.com/bhabakjishnu/Animated-Ui-Theme-Pack)
> Reusable motion architecture and UI component showcase powered by modern CSS transformations.

- **Architecture**: Tokenized animation system encapsulating timing curves, elevation states, and transitions.
- **Key Technical Highlights**:
  - Hardware-accelerated 2D transformations (`translate3d`, `scale`) for smooth 60fps rendering.
  - Modular theme tokens allowing instant theme palette reconfigurations.
- **Stack**: `Modern CSS3` • `Keyframe Animations` • `GPU Transforms`
- **Links**: [Repository](https://github.com/bhabakjishnu/Animated-Ui-Theme-Pack) &bull; [Live Demo](https://bhabakjishnu.github.io/Animated-Ui-Theme-Pack/)
